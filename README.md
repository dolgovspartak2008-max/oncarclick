# ON Car Click

Сайт ON Car Click с живым каталогом автомобилей из Южной Кореи. Данные, фотографии и рассчитанная стоимость до Владивостока загружаются из публичного каталога Trust Encar.

## Как работает каталог

- `public/` содержит исходный дизайн сайта без смены визуального стиля.
- `/api/catalog` получает и нормализует автомобили Trust Encar.
- Ответы сохраняются в серверном кеше на 24 часа.
- Vercel Cron ежедневно в 02:00 UTC (07:00 по Екатеринбургу) обновляет кеш.
- Если источник временно недоступен, браузер показывает последнюю успешно загруженную страницу каталога.
- Цена Trust Encar «до Владивостока» уже содержит его пошлину (`TAMOG_P`) и его утильсбор (`UTIL`). Мы их вычитаем и ставим свои: итог = машина в Корее + расходы ON Car Click + утильсбор + пошлина (`src/domain/car-price.ts`). Расходы Trust Encar (комиссия, фрахт, брокер, стоянка, таможенный сбор) заменены нашими из `src/domain/expenses.ts`: до 3 лет — 80 000 (расходы по Корее и доставка до Владивостока) + 230 000 (Владивосток → Москва) + 60 000 (растаможка в Беларуси: Москва → Беларусь → Москва), с памяткой, что такие машины растаможиваются в Беларуси (Москва → Беларусь → Москва); от 3 лет — только 80 000 (расходы по Корее и доставка до Владивостока), дальше маршрут считается индивидуально. Скидка 40 % на пошлину уже внутри строки «Таможенная пошлина», отдельно не показывается. Ничего не начисляется дважды.
- Утильсбор — по таблице заказчика (`src/domain/recycling-fee.ts`): объём двигателя × мощность × год ввоза × возраст (до 3 лет / 3–5 лет). Если источник не указал мощность, берётся утильсбор источника.
- Таможенная пошлина — единственная функция `calculateCustomsDuty` в `src/domain/customs-duty.ts` (ставки ЕАЭС для физлиц, личное пользование; таблицы ставок — в начале файла). Возраст — от даты производства (15-е число месяца, только год — 1 июля) до даты расчёта по Москве. Курсы — официальные ЦБ на сегодня (`src/server/customs-rates.ts`: cbr.ru → cbr-xml-daily.ru → курсы ЦБ со страницы Trust Encar), кеш 3 часа. Для машин строго младше 3 лет клиент платит 60 % официальной пошлины — это коммерческая корректировка ON Car Click, оба значения хранятся (`customs.officialDutyRub`, `customs.customerDutyRub`, `customs.commercialAdjustmentRub`). Электромобили и машины без объёма/даты — `calculationStatus: "needs_review"`, в цене остаётся пошлина источника.
- Фильтры: марка, модель, поколение, комплектация, год «от–до» (колёсики), пробег шагом 10 000 км и цена под ключ «от–до» (бюджет). Бюджет отбирается по нашей итоговой цене: у Trust Encar запрашивается диапазон его цены с запасом (`sourcePriceWindow`), затем машины пересчитываются и отбираются точно (до 15 страниц выдачи, как для комплектации). `/api/catalog?count=1` возвращает число машин для кнопки «Показать N авто», `/api/catalog/options` — модели, поколения и комплектации.
- Поколение превращается в диапазон годов выпуска. Комплектацию источник не фильтрует, поэтому сервер просматривает до 15 страниц выдачи и считает совпадения сам (для очень больших моделей число помечается «около»).
- Избранное хранится в браузере посетителя (`public/js/favorites.js`), страница — `favorites.html`.
- Заявки (`/api/lead`): не больше 3 заявок с одного IP за 10 минут и 10 за сутки, иначе ответ 429. IP в базе не хранится — только его хеш (SHA-256 с `BOT_DB_SECRET`). Повторная заявка с того же телефона в течение 10 минут сохраняется, но в Telegram не дублируется. Проверки — в функции базы `site_add_lead` (`supabase/migrations/`).
- Telegram-бот (`/api/telegram`): заявки с формы сайта приходят администраторам, отзывы добавляются пошагово и сразу видны на главной, курс воны пересчитывает цены каталога. Доступ к боту — только у администраторов из таблицы admins (добавляются вручную в базе); бот отвечает только в личных чатах и проверяет права по Telegram ID пользователя. Данные — в Supabase (таблицы reviews, settings, admins, leads), запись только через функции базы с серверным секретом. Настройка вебхука — см. «Настройка Telegram-бота» ниже.
- В репозиторий не записываются пароли, токены или другие секреты.

## Локальный запуск

Требуются Node.js 22+ и pnpm 11+.

```bash
pnpm install
pnpm dev
```

Сайт откроется на `http://localhost:3000`, каталог — на `http://localhost:3000/catalog.html`.

## Проверка

```bash
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

## Развёртывание

Проект рассчитан на Vercel: импорт каталога и ежедневное обновление требуют серверных функций, поэтому GitHub Pages для этой версии не подходит.

1. Подключить репозиторий к Vercel.
2. Framework Preset определяется автоматически как Next.js.
3. Добавить переменные из `.env.example`. `CRON_SECRET` обязателен: без него синхронизация отвечает 401. Vercel передаёт его ежедневному cron-запросу автоматически.
4. Выполнить Deploy.

Ручная проверка синхронизации:

```bash
curl -H "Authorization: Bearer $CRON_SECRET" https://YOUR-DOMAIN/api/internal/sync
```

## Настройка Telegram-бота

После деплоя (и после каждой смены `TELEGRAM_WEBHOOK_SECRET`) один раз вызвать:

```bash
curl -X POST -H "x-setup-key: $TELEGRAM_SETUP_SECRET" https://YOUR-DOMAIN/api/telegram/setup
```

Ключ принимается только из заголовка `x-setup-key` (не из адреса). Адрес вебхука берётся из `SITE_URL`, а если её нет — из `VERCEL_PROJECT_PRODUCTION_URL`. При ошибке ответ — только `{ "ok": false }`, подробности — в логах Vercel.
