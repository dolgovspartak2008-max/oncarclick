# OnCarClick — сайт (прототип)

Статичный сайт-макет «Авто под заказ из Кореи, Японии и Китая». Адаптирован под телефон (mobile-first), всё кликабельно.

## Устройство
**`index.html`** — главная, разделы идут друг за другом:
1. `#home` — главная (вступительная анимация — `js/intro.js`: машина подъезжает с вращающимися колёсами, тормозит, зажигает фары, затем флаги и текст; слои — `assets/img/intro/`)
2. `#about` — о компании
3. `#catalog` — кнопка «Перейти в каталог» → `catalog.html`
4. `#deal` — как проходит сделка (7 этапов)
5. `#reviews` — отзывы (слайдер карточек)
6. `#faq` — частые вопросы
7. `#contacts` — контакты и форма заявки

**`catalog.html`** — каталог. Три зависимых фильтра: марка → модель → объём двигателя (каждый список показывает только варианты, которые есть при выбранных остальных). Можно открыть с фильтром: `catalog.html?brand=Toyota&model=Camry`.

Данные машин — `js/cars-data.js`: `price` — итоговая цена под ключ в рублях, `engine` — объём двигателя в литрах (0 — электромобиль).

## Что пока заглушки
- Машины в каталоге (`js/cars-data.js`) — нарисованные силуэты и демо-цены, вместо них нужны реальные фото и данные.
- Отзывы — шаблоны с пометкой «Пример», заменить на реальные отзывы клиентов.
- Контакты (Telegram, WhatsApp, телефон, почта) — из макета, заменить на настоящие.
- Форма заявки показывает «Отправлено», но никуда не отправляет.

## Как открыть
Просто открыть `index.html` в браузере, или включить GitHub Pages (Settings → Pages → main / root).
