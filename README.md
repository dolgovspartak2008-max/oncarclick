# OnCarClick — сайт (прототип)

Статичный сайт-макет «Авто под заказ из Кореи, Японии и Китая». Адаптирован под телефон (mobile-first), всё кликабельно.

## Устройство
**`index.html`** — главная, разделы идут друг за другом и листаются прокруткой:
1. `#home` — главная (машина в порту)
2. `#about` — о компании
3. `#catalog` — кнопка «Перейти в каталог» → раскрывается выбор: до 3 лет / от 3 до 5 лет / от 5 лет и старше
4. `#calculator` — калькулятор стоимости «под ключ»
5. `#reviews` — отзывы (слайдер карточек)
6. `#contacts` — контакты и форма заявки

**`catalog.html`** — отдельная страница каталога. Возраст выбирается вкладками и адресом: `catalog.html?age=new` (до 3 лет), `?age=mid` (3–5 лет), `?age=old` (от 5 лет), без параметра — все.

Меню на телефоне (☰) и фильтры каталога открываются отдельным экраном на весь дисплей.

Данные машин — `js/cars-data.js`.

## Что пока заглушки
- Машины в каталоге (`js/cars-data.js`) — нарисованные силуэты и демо-цены, вместо них нужны реальные фото и данные.
- Отзывы — шаблоны с пометкой «Пример», заменить на реальные отзывы клиентов.
- Формулы калькулятора упрощённые.
- Контакты (Telegram, WhatsApp, телефон, почта) — из макета, заменить на настоящие.
- Форма заявки показывает «Отправлено», но никуда не отправляет.

## Как открыть
Просто открыть `index.html` в браузере, или включить GitHub Pages (Settings → Pages → main / root).
