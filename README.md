# OnCarClick — сайт (прототип)

Статичный сайт-макет «Авто под заказ из Кореи, Японии и Китая». Адаптирован под телефон (mobile-first), всё кликабельно.

## Устройство
Весь сайт — одна страница `index.html`, разделы идут друг за другом и листаются прокруткой:
1. `#home` — главная (машина в порту)
2. `#about` — о компании
3. `#catalog` — каталог: поиск, фильтры (на телефоне — шторка снизу), сортировка, избранное, по 2 карточки в ряд на телефоне
4. `#calculator` — калькулятор стоимости «под ключ»
5. `#contacts` — контакты и форма заявки

Меню (на телефоне — кнопка ☰) плавно прокручивает к разделу и подсвечивает тот, который сейчас на экране. Внизу — футер и кнопка «наверх».
Старые адреса `about.html`, `catalog.html` и т.д. перенаправляют на нужный раздел.

## Что пока заглушки
- Машины в каталоге — нарисованные силуэты и демо-цены, вместо них нужны реальные фото и данные.
- Формулы калькулятора упрощённые.
- Контакты (Telegram, WhatsApp, телефон, почта) — из макета, заменить на настоящие.
- Форма заявки показывает «Отправлено», но никуда не отправляет.

## Как открыть
Просто открыть `index.html` в браузере, или включить GitHub Pages (Settings → Pages → main / root).
